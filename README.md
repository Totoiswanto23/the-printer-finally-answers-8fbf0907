The printer finally answers back: "You thump me like that again and I'll print your search history." — years of jams, cryptic error codes and thumps, and the machine finally threatens back with the one thing it can print that nobody wants printed. Weary, literal, and faintly passive-aggressive: the printer getting to talk back is the comeback.
